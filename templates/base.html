概念 · 目标 · 愿景

理解现在，推演后果

本站采用一个任务导向的工作定义：世界模型是环境动力学模型，根据历史观测形成状态摘要，预测未来如何演化；用于决策时，还要能推演候选动作的后果。

我们希望它带来什么

研究目标，不是默认拥有的能力
01

保留重要信息

不必重建所有细节，但不能丢掉决定未来的状态。部分可观测、延迟和历史记忆都可能重要。

02

比较不同未来

给定同一段历史，比较不同动作与外部场景下的多步轨迹，检查累积误差和失效范围。

03

支持可靠决策

用预测辅助规划或学习行为，并报告不确定性。超出数据与机制支持时，能暂停建议或转交判断。

预测、干预与反事实有不同证据要求。动作条件输入不自动带来因果识别；针对某次已发生事件的反事实，还需要更强的结构与外生条件假设。
把这个定义落到 IT / 云系统

以扩容为例：输入是操作前的负载、指标历史、配置与拓扑，候选动作是扩容时机和规模，输出应包括延迟、错误率、资源代价随时间的变化。实例启动与流量重分配的延迟、观测缺失和外部负载变化，都可能改变结论。这是建模任务示例，未声称本站已经实现。

建模可从机制模型、系统辨识、神经网络或混合系统开始；是否采用 LLM、是否训练策略取决于任务。只有故障名称或根因标签的数据，不能直接提供不同恢复动作后的状态轨迹。迁移需要记录动作实际生效时间、上下文与后续观测，并在受控环境检验多步误差和失效范围。

定义参考：World Models（2018）、DreamerV3。上面的 IT 示例是本站的任务分析，不是论文已证明的生产能力。

放回今天的 AI 体系

三个概念，三个层面
模型形态

LLM

可以承载世界知识、结构化信息或被训练为动力学模型的一部分。流畅解释本身不是操作后果准确的证据。

建模能力

World Model

负责表征环境并预测变化。可以是神经网络、机制模型或混合系统，是否有用由任务与验证决定。

行动系统

Agent

选择并执行动作，可以调用世界模型比较方案。agent 不等于世界模型，世界模型也不必附带自动执行。

IT VISION

在真实操作之前，先问一次“会怎样”

变更前估计扩容、发布、回滚的影响范围与代价

处置中比较限流、隔离与保持不变的恢复轨迹

风险外识别未知场景，保留人审与安全边界

这是一条待验证的 IT 研究愿景。先证明预测与风险评估有效，再谈闭环控制；不从机器人/游戏结果直接推断生产可用。

V-JEPA 2

V-JEPA 2: Self-Supervised Video Models Enable Understanding, Prediction and Planning

2025 原论文 · 本页按 v1 导读
原论文 代码

问题

如何把从视频学到的表征，进一步用于预测动作后果和选择动作？

机制

先做 action-free 视频表征预训练；再用机器人交互数据训练动作条件预测器，形成 V-JEPA 2-AC，并用于目标导向规划。

实际证据

论文分别研究视觉理解/预测，以及机器人规划与操作；动作条件阶段需要交互数据，并非仅靠被动视频完成控制。

边界

机器人设置中的证据不能直接外推到 IT 运维。动作条件预测也不自动满足因果识别条件。

沿这条线读原文

  1. 先分开两个训练阶段

    在方法部分标出 base model 和 V-JEPA 2-AC。前者从视频学习表示；后者引入动作与机器人状态，学习可用于规划的预测器。

  2. 再看预测目标和规划目标

    预测的是目标表征；规划在候选动作序列中寻找能接近目标表示的方案。可用表征和可用控制器不是同一个结果。

  3. 最后对齐结果与数据

    将视觉理解、动作预判和机器人控制分栏记录；不要用前两类分数替代“执行某动作会发生什么”的验证。

V-JEPA 2.1: Unlocking Dense Features in Video Self-Supervised Learning

2026-03 首稿 · 2026-06 v3 更新
原论文

问题

如何在保留全局理解的同时，学到更有空间结构和时间一致性的 dense features？

机制

结合 dense predictive loss、多层深监督、图像/视频统一训练以及模型与数据扩展。

实际证据

作者报告交互预判、深度/导航及机器人抓取等结果；本提纲未独立复现实验。

边界

更好的 dense features 不等于所有动作效果已识别；不要把 action anticipation 与 action-conditioned control 混为一谈。

Genie

Genie: Generative Interactive Environments

2024 预印本
原论文

问题

没有动作标注，是否仍能从视频学习可逐帧交互的环境？

机制

组合视频 tokenizer、自回归动力学与 latent action model；学习潜在动作以控制后续生成。

实际证据

作者展示可由图像等提示建立并逐帧控制的虚拟环境，以及潜在动作空间的用途。

边界

潜在动作的可控性，不保证对应真实系统中语义固定、可执行的操作。

带着这个问题读

latent action 从何而来？它的可控性与真实动作可解释性之间差在哪里？

问题

机制

RouteNet-Gauss

RouteNet-Gauss: Hardware-Enhanced Network Modeling with Machine Learning

2025 预印本 · IEEE Transactions on Networking 2026
原论文

问题

如何结合真实测试床与机器学习，预测网络场景在可配置时间粒度下的性能？

机制

按 flow、queue、link、device 组合消息传递，跨时间窗保留状态，生成流级性能估计。

边界
